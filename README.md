## 🎓 Udemy Clone – Frontend Website (HTML & CSS)

This project is a **frontend-only clone** of the popular Udemy website, built entirely with **HTML5** and **CSS3**. It focuses on recreating the **layout, design, and user interface** of Udemy’s core pages, offering a clean and responsive user experience. This clone does not include any backend or interactive functionality—its purpose is purely visual and structural, making it ideal for frontend practice and UI/UX design learning.

---

### ✨ Key Features:

* ✅ **Fully responsive design**: Optimized for desktops, tablets, and mobile devices using media queries.
* ✅ **Navigation bar**: Includes logo, search bar, and login/signup buttons for a realistic header section.
* ✅ **Hero section**: Designed with a banner and a call-to-action, mimicking Udemy’s promotional layout.
* ✅ **Course categories**: Displays popular topics and categories using structured content blocks.
* ✅ **Course cards**: Visually styled course previews with image, title, instructor name, rating, and price.
* ✅ **Course detail layout**: A sample static design showing what a course page might look like.
* ✅ **Footer**: Includes useful links, language selector, and placeholder social media icons.
* ✅ **Hover effects and transitions**: Enhance interactivity through pure CSS.

---

### 🛠️ Technologies Used:

* **HTML5** – For semantic page structure and content layout.
* **CSS3** – For styling, layout control, and animations.
* **Flexbox & CSS Grid** – To create modern, flexible layouts.
* **Media Queries** – For building a mobile-first responsive experience.
* **Google Fonts / Font Awesome** *(optional)* – For icons and custom typography.

---

* Practicing frontend development with real-world designs.

* Learning HTML/CSS layout techniques.
* Gaining hands-on experience in responsive web design.
